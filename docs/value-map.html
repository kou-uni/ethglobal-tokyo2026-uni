Intercepta

World ID

この承認に、人が関与した証拠。

⑤ 支払いの境界

autoまたは承認後にfacilitatorが決済。宛先・金額は署名に固定。結果はチェーンの取引と照合する。

事業として何を売る？

「依頼を判断する仕事」への従量課金が構想。売り手への対価とは別に、買い手から手数料を受け取る設計。判定台帳・任意の別署名の保持まで実装し、回収は未実装。顧客の支払意思・導入需要は未検証。
