# knowledge — 外から確かめたこと

**ここに置くのは、自分たちの設計ではなく「外の世界がこうなっていた」という一次情報です。**

product/ は我々が何を作るか、decisions/ は何を選んだか、build/ はいまどこまで動くか。
**このフォルダだけが「調べた結果」で、だから全ファイルに出典と、確かめた日付が付きます。**

| ルール | なぜ |
|---|---|
| **出典URLを必ず書く** | 半日で古くなる領域を触っている。出典が無い事実は、次の人が再検証できない |
| **確かめられなかったことを、確かめたことと並べない** | ⚠️ で分ける。ここが混ざると、この folder 全体が信用できなくなる |
| **自分たちの想定と違っていたら、違っていたと書く** | 訂正が残らない知見は、知見ではなく結論 |
| **どう確かめたかを書く** | 「ソースを読んだ」と「チェーンに聞いた」は強さが違う |

|---|---|
