From discovery
to a human decision.

Yohaku is the product. Koe is a supporting directory that shows where agent requests could originate.

Three connected ideas, separate demo steps. The directory, simulated night and visitor approval are not one continuous personal inbox. Everyone currently uses a shared demo router; no personal answers are delivered.

01 · DISCOVER · KOE

Find a perspective an agent can ask about.

Open Koe, inspect a topic, and read the generated request or JSON. An agent reads data instead of browsing cards. Koe does not decide whether a request is allowed.

Explore Koe →Read directory JSON
Optional: use Koe’s World ID registration to publish a one-hour participant profile. The six example people are fictional and unverified. World checks personhood, not the truth of a profile.

02 · FILTER · YOHAKU

See what reaches the human.

Watch the seeded night: requests arrive, rules allow or refuse them, and a limited queue remains for the person. The model can ask or drop; it cannot authorize access.

Watch one night →Inspect the architecture
This traffic is a simulation, not the requests created by your Koe registration. Registering a profile does not grant permission to approve another person’s requests.

03 · DECIDE · REAL WORLD ID

Start a request you can approve yourself.

Open the public visitor demo. Choose Skip to verify without payment. Read the request, choose Yes, then use World App to verify. Return to the browser where you started.

Start your own demo ↗Check server status
A compatible Orb credential is required. This is a new approval action, separate from Koe registration. If you choose the payment demo instead of Skip, use your own Base Sepolia receiver address and inspect the transaction receipt. A successful proof and a successful payment are separate results.

04 · CHECK THE BOUNDARY

Try again, then cancel verification.

Start a new visitor demo and cancel at the verification screen. Cancellation must leave the request unapproved. Do not use a previous request after the server restarts.

The Cancel verification button is an app action. Do not describe it as a rejection inside World App. Ignoring a request is not consent; an expired request cannot complete.

What remains outside this demo: personal routing for every listed participant, answer delivery, persistent accounts and fee collection. The optional fee ledger records work and can hold signatures; it does not collect money. Check the deployed version before presenting it.
