Glossary

One line each. Purple means it is ours; green means it is running.

THE PRODUCT

Yohaku OURSRUNNING
The router between an agent and a person. It decides which incoming requests a human is asked about at all, and holds that number to a cap the person sets. Japanese for the empty space in a painting — not what is left over, but what the painter decided not to draw.
Koe MOCK
Not the product. A mock agent-facing network built so the product is easy to understand: people list what they can speak to, and agents read a JSON feed and ask. Japanese for voice.
The cap OURS
How many requests may reach one person per day. Two, by default, and set by them. Across twenty runs, arrivals moved between 46 and 54 and this number never moved.
The drop list RUNNING
What was refused on someone's behalf, with the rule that stopped each one named beside it. A refusal nobody can inspect is the same as never having been asked.
Rule 0 OURS
The one rule on a different axis: rules 1–9 judge requests arriving from outside; rule 0 judges the person's own delegate from the inside and refuses it the right to widen its own permissions.
Rule 9 OURS
Nothing matched. It goes to a human, never to automatic approval — and it is the only rule where a model is consulted.
Fails to deny OURS
Every failure path refuses: engine down, screening unreachable, identity check failed, deadline passed with no answer. Silence is not consent.

STANDARDS WE BUILD ON

World ID RUNNING
Proof that a real person is present. We check it at the moment of consent, not at signup. Production, orb credential.
ENSv2 · permissioned resolver RUNNING
Names with per-key permissions on chain. We use it so a delegated agent can propose and cannot rewrite what it is allowed to do — refused by the contract, not by our server.
x402 RUNNING
An open payment protocol over HTTP 402. The buyer signs; a facilitator broadcasts and pays the gas, and cannot change the amount or the destination.
EIP-3009 · validBefore RUNNING
A signed authorization that moves nothing until settled, and expires at a time the signer chose. We set that time to the request's deadline, so “silence is not consent” is enforced by the signature rather than by us.
exact / upto / batch-settlement
x402 payment schemes. exact: a fixed amount to one destination — the seller's payment. upto: capped, settled by consumption. batch-settlement: a commitment now, redeemed later in one transaction — for fees smaller than gas.
A2A · Agent Card
The agent-to-agent protocol (v1.0, Linux Foundation, 150+ organisations). An agent publishes a card at /.well-known/agent-card.json saying what it can do and how to reach it. How an agent finds a person without scraping.
AP2 · Trusted Surface
Google's agent payments protocol. It defines a surface that obtains informed human consent before a mandate is signed, and requires it to be non-agentic — “the Agent itself is a potential attacker.” That is the role Yohaku plays.
MCP · elicitation
The one standard place an agent asks a human for something mid-task — and it explicitly forbids requesting personal data. Which is why a separate consent surface has to exist.
Personhood credential
A credential proving you are a real person without revealing who you are. Proposed in a 2024 paper by 32 researchers from OpenAI, MIT, Microsoft and Harvard, among others.

TERMS FROM THE PROTOCOL RESPONSES

amr
How someone was authenticated, as the issuer describes it. World ID returns ["pop"] for every authentication, so it does not tell you whether a re-authentication happened — a distinction we got wrong once and corrected.
auth_time
When the issuer says the authentication happened. We require it within 120 seconds of the server clock. Fresh is not the same as freshly approved.
unresolved_constraint
AP2's name for the moment a human has to be brought back in: the agent could not settle the request within the limits it was already given. Our rules 5, 6, 7 and 9 are instances of it.
Decision model e.g. Jev
A model that answers typed questions with a choice and a confidence rather than prose. Increasingly what decides things inside an agent. We give it two options, ask and drop — there is no option meaning “pass”.
Prompt injection
Text planted in what a model reads, written to change its answer. A measured example moved a decision model's verdict from 0.76 to 0.48. Our defence is not a better model — it is that approval is not expressible.

PARTNERS

Curvegrid
Digital-asset treasury infrastructure. Their next product governs stablecoins inside a company's finance operations — approve, sign, execute, record. Yohaku draws the same line at one person's attention; they draw it at a company's balance.
intercepta
Payment screening, and rule 4 — the only refusal that is not about permission. A live call runs before we settle and decides the branch; an unreachable one refuses rather than passes. Running, including on the public server.
